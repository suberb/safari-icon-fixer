# Native promotional captures

On macOS, after building 0.7.0 with `bash Build.command`, close any previously opened demo window. Run from the repository:

```bash
open -na "$PWD/build/Safari Icon Fixer.app" --args --demo
```

This starts the isolated demonstration rather than the live library. The demo contains eight fictional Favorites. No permissions are needed. Do not capture an existing real library window, notifications, desktop, or private data.

Suggested shots (use macOS Shift-Command-5, then capture the demo window):

1. Initial demo with three missing sample icons.
2. Quick Repair and After, with all sample icons restored.
3. Orbit selected, Smart Color or Amethyst chosen, and margin adjusted.
4. Repeat in dark appearance; optionally record a short silent clip demonstrating the same controls.

Review captures before including them in GitHub or the product website. Remove any identifying metadata, and prefer WebP or optimized PNG for screenshots and MP4 for clips. Do not label the existing HTML diagrams as native screenshots. Do not publish raw desktop recording. This guide does not automatically capture or upload anything.
