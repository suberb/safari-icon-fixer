## Safari Icon Fixer 0.6.6 — Color Studio+

- Smart Color suggests a background based on logo color and brightness; the existing Soft Brand lightening control remains available.
- Seven presets: Original White, Soft Brand, Midnight, Amethyst, Pastel, Sandstone, and Smart Color. Style selected icons or the visible set (drafts only). Complex backgrounds are skipped in batch mode.
- Export saved protected icons from your selection or current folder and import a portable `.sifcollection.json` file. Review matching domains before preparing changes. Existing drafts are never overwritten by imports. Collections contain domain names, normalized PNG artwork and display styles: share only with trusted people.
- Existing icon protection, backups, six interface languages, signed Sparkle updates, and manual Apply safeguards remain.

Safari must be closed before applying, resetting or restoring icons. The app is ad hoc signed, not Apple-notarized. Safari's cache is undocumented; compatibility is not guaranteed.
