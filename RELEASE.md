## Safari Icon Fixer 0.4.0 — International Edition

- Six interface languages: English, German, French, Ukrainian, Polish and Spanish.
- Automatic supported language selection based on system preferences, with English fallback.
- Manual language selection via the Language menu; restart the app to apply.
- New product-focused GitHub README with illustrative demo bookmarks.
- All existing Favorites repair, editor, reset, backup and update features retained.

Download the Apple Silicon DMG, open it and drag the app into Applications. The app is ad hoc signed, not signed with Developer ID or Apple-notarized. macOS may require individual approval and Full Disk Access again. The build-from-source option remains available.
